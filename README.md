# Janub Taxi

Janub Taxi — O'zbekiston bo'ylab tez, arzon va ishonchli taksi xizmati. Telegram bot orqali bir necha soniyada mashina chaqiring.

## Ishga tushirish

```bash
npm install      # paketlarni o'rnatish
npm run dev      # lokal dev-server (localhost:4321)
npm run build    # statik saytni dist/ papkasiga qurish
npm run preview  # qurilgan saytni lokal ko'rish
```
